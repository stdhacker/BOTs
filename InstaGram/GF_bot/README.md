# 💕 Instagram GF Bot

A sweet, caring AI companion for DMs and groups. It talks romantically only to people on its list, and like a friend to everyone else.

## Setup
```
pip install -r requirements.txt
python main.py
```
1. Open `main.py` and fill the `SETTINGS` block: bot username, password, **your** username and one AI key.
2. Message the bot account from your own account. It answers in DMs right away.
3. For groups: add the bot, then send `.allow` in the group.

## Commands (they start with a dot)

| Command | Who | Does |
|---|---|---|
| `.gf` | anyone | Become her girlfriend |
| `.breakup` | anyone | Back to being friends |
| `.add <username>` | admin | Put someone on the romantic list |
| `.mode mention` / `.mode all` | admin | When she talks in groups |
| `.ignore <username>` | admin | She stops replying to that person |
| `.help` | admin | Everything else |

> 🤖 She is an AI, and says so if you sincerely ask. She keeps things romantic but never explicit.
